# 违章警报 ViolationGuard

一款 Android 应用：当手机收到疑似**交通违章 / 违停 / 挪车**短信，
且短信中包含你绑定的车牌号时，立即发出**持续警报声 + 震动 + 全屏红色警报界面**，
避免错过交警的挪车、处罚提醒。

## 功能

- 绑定多个车牌（本地保存，可添加 / 删除）
- 收到命中车牌的疑似违章短信时：
  - 全屏红色警报界面，点"停止警报"关闭
  - 5 种警报声可选：警车警笛、消防车警笛、救护车警笛、防空警报、电子蜂鸣
  - 警报声用闹钟通道最大音量循环播放，不会被普通短信提示音盖住
  - 持续震动 + 高优先级通知
- 总警报开关
- 本机运行，不联网、不上传任何数据

## 短信匹配规则

必须先命中任一已绑定车牌，再满足以下之一：

- 发件人疑似官方：`12123` / `1069` / 交警 / 公安 / 交管
- 内容含关键词：违章、违法、违停、处罚、扣分、罚款、违法停车、
  未按规定停放、已被记录、违法行为、额章、移开、挪车、驶离、拖移

## 安装

1. 在 [Releases](../../releases) 页面下载最新版 APK
2. 在手机上允许"安装未知应用"后安装
3. 打开 App，按提示授予：**短信权限**、**通知权限**、**后台弹出界面**权限
4. 添加车牌号，打开总警报开关

注意：App 必须装在**接收交管短信的那台手机**上。
部分国产手机（小米 / 华为 / OPPO / vivo 等）需在系统设置中允许自启动、
允许后台弹出界面，否则锁屏时可能无法响铃。

## 权限说明

| 权限 | 用途 |
| ---- | ---- |
| 接收短信 | 监听交管短信，无此权限无法工作 |
| 通知 | 发送高优先级警报通知 |
| 后台弹出界面 | 短信到达时直接弹出全屏警报界面（亮屏 / 锁屏都能响） |

## 构建

用 Android Studio 打开本项目即可编译（minSdk 26，targetSdk 34）。
Release 包需自行生成签名密钥并签名，签名密钥请勿提交到仓库。
